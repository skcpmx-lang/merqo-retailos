## 1. Objectives & Design Direction

- Make MERQO RetailOS feel premium, trustworthy, calm, professional, efficient, desktop-native, Bengali-first, information-dense not cluttered.
- Light theme only, Noto Sans Bengali + Inter, Lucide icons only.
- No generic admin template, AI dashboard, landing page, gaming, glassmorphism, neon SaaS.
- Preserve design tokens, but consolidate for calm enterprise palette.
- Priority: clarity → speed → consistency → Bengali readability → accessibility → visual polish.
